Práctica RA5 · a+b — Datos e información
1) Caso
Sistema: Netflix
Contexto: Plataforma de streaming que recopila datos de uso de los usuarios para recomendar contenido personalizado y mejorar su catálogo.

3) Datos
Hora de inicio de sesión
Películas o series reproducidas
Tiempo de visualización
Dispositivo utilizado (móvil, TV, PC)
Ubicación aproximada del usuario
Valoraciones (likes/dislikes)
Búsquedas realizadas

4) Información
Contenido más popular por región
Preferencias del usuario (género favorito, duración media)
Horas pico de consumo
Tasa de abandono de una serie o película
Recomendaciones personalizadas para cada usuario

5) Diferencia
Dato: Es un valor bruto sin interpretar (ej: “usuario vio 45 minutos de una serie”).
Información: Es el resultado de analizar y contextualizar datos (ej: “los usuarios abandonan esta serie antes del episodio 2”).

6) Ciclo del dato
Captura: Se registran acciones del usuario en la app (clics, reproducciones).
Almacenamiento: Los datos se guardan en bases de datos en servidores.
Procesamiento: Se organizan, limpian y transforman (ej: eliminar duplicados).
Análisis: Algoritmos detectan patrones y tendencias.
Uso: Se generan recomendaciones y decisiones empresariales.
Eliminación: Datos antiguos o innecesarios se eliminan o archivan según políticas.
